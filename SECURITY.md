# Security policy

## Supported version

Security fixes are prepared for the hosted Limited Free Developer Beta and the
latest published package beta only.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email
`security@dermoptera.work`. The mailbox is monitored through a tested forwarding
route. Use GitHub private vulnerability reporting when it is available for this
repository.

Include the affected package or endpoint, impact, reproduction steps, and any
suggested remediation. Do not include real end-user state, live credentials, or
third-party personal data. Dermoptera will acknowledge a complete report when a
monitored disclosure channel exists; no response-time SLA is offered during beta.

## Scope

In scope: SDK cryptography and fragment handling, hosted transfer endpoints,
one-time claim behavior, TTL, Project credentials, Origin controls, quota and the
Developer Dashboard. Out of scope: social engineering, denial-of-service traffic,
automated scanning that creates material load, and testing with data you do not own.
